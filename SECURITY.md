# Security reports

Please report reproducible issues against the latest source revision. Older
versions do not have a separate security maintenance commitment.

For vulnerabilities or reports containing sensitive information, use GitHub's
**Report a vulnerability** option in this repository's Security tab when available.
If private reporting is unavailable, email the maintainer at
**serdar.ozay@gmail.com** with the subject **Leaf security report**. Include the
affected revision, impact, and minimal reproduction steps. Do not include API
keys, private books, or other people's data. Avoid publishing exploit details in
a public issue before the maintainer has had an opportunity to investigate.

Ordinary bugs and feature requests belong in
[GitHub Issues](https://github.com/searchrome/leaf/issues). Leaf is maintained on a
best-effort basis; no response deadline is promised.
