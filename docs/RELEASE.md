# Release preparation

## Source release

Leaf's original source, sample book, and generated icon are licensed under the
[MIT License](../LICENSE). The optional downloaded speech runtime and hosted
services have separate terms documented in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Before publishing a source release:

1. Run `swift test` and `REGISTER_APP=0 bash scripts/package.sh` on macOS.
2. Review documentation and known limitations in the README and [TICKETS.md](TICKETS.md).
3. Review tracked files and Git history for credentials, personal data, and material
   you cannot redistribute. The source exporter excludes history; making a Git
   repository public also exposes its history.
4. Run `python3 scripts/package-source.py --require-license`.
5. Extract `dist/Leaf-source.zip` into a clean directory and run its tests and
   package script. The archive includes `SOURCE_MANIFEST.json` with file hashes.
6. Publish release notes with supported macOS versions, architecture, and known
   limitations. Source availability and a downloadable notarized app are separate
   release milestones.

The exporter uses an allowlist to exclude Git history, application data, books,
installed models, build caches, signed binaries, and historical QA notes. It also
rejects external symlinks and common private-key patterns. Review the delivered
files as well; pattern checks cannot identify every possible secret.

The GitHub Actions workflow runs ordinary tests, app packaging, and source export
on macOS. It does not download Kokoro or make paid API calls.

## Building an app

Install Xcode command-line tools with Swift 5.9+ on macOS 13+. Run `swift test`,
then `bash scripts/package.sh`. Launch `dist/Leaf.app` so app resources,
preferences, Keychain identity, and Dock icon resolve correctly. The default
build targets the build machine's architecture. Local Kokoro additionally
requires native Apple Silicon and macOS 14+; Mac voices remain available on
supported Intel builds.

Python 3.9+ is needed only for source-export and audit helper scripts. End users
obtain the optional local speech runtime through Settings.

## Branding and signing

Application name, bundle identifier, version, and build are in
`packaging/Info.plist`. The icon is generated by `packaging/generate-icon.swift`.
Keep a stable bundle identifier for upgrades: changing it creates a new
preference/Keychain identity.

The package script includes the MIT license and third-party notices in the app's
Resources directory. Its default ad-hoc signature is for local development.
With a Developer ID certificate installed, build using:

```sh
SIGNING_IDENTITY="Developer ID Application: Your Company (TEAMID)" bash scripts/package.sh
```

This enables hardened runtime and timestamped signing. `REGISTER_APP=0` skips
local Launch Services registration for CI. Keep signing certificates, private
keys, Apple credentials, and Keychain exports out of source and release archives.

For downloadable app distribution, complete Apple's notarization and stapling
workflow and test the final artifact on a clean Mac. The current app is not
sandboxed and optionally downloads executable runtime components; App Store
submission would require separate work.

## Dependencies and manual qualification

Read [DEPENDENCIES.md](DEPENDENCIES.md) and the third-party notices before bundling
optional dependencies. The source archive and standard app package do not bundle
the downloaded Kokoro runtime or weights. Preserve upstream notices and review
redistribution requirements if including them in a future release.

The checked-in dependency audit is dated, rather than a guarantee about future
advisories. Refresh it after package updates. Before shipping a new app version,
exercise import, per-book restoration, native/local narration, pause/resume,
sentence navigation, display wake protection, library removal, missing files,
provider changes, and cancellation on the macOS versions and architectures you
plan to support. [the repository verification record](https://github.com/searchrome/leaf/blob/master/docs/VERIFICATION.md) records previous checks and
remaining manual qualification.
