# Design guide

The maintained architecture and source-file map is [ARCHITECTURE.md](ARCHITECTURE.md). Product behavior and supported features are described in [README.md](../README.md). Release preparation and source delivery are documented in [RELEASE.md](RELEASE.md).

The reading interface uses warm paper colors, green controls, serif text, a chapter/bookmark sidebar, and a persistent playback footer. Text selection, reading, and narration share the canonical imported text and UTF-16 offsets. Generated-audio following is explicitly labeled as estimated when source-aligned timestamps are unavailable.
